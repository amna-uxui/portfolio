UNICOS Framework Implementation

UNICOS was born at CERN in early 2001 with the development of the LHC cryogenics control system. It deals with the two upper layers of a classical control system: Supervision and Control. UNICOS proposes a method to design and develop the control application which will run in commercial off-the-shelf products (e.g. SCADA and PLCs).

Additional functionality - Dark mode of UNICOS:

I also implementing dark mode for UNICOS, allowing users to seamlessly switch between light and dark modes via the HMI. This process includes designing a color database, theme specific icons, and optimizing the code for a smooth user experience.

  • Comprehensive design guideline document for future development.
