Logitech - PWS Keyboard Layout

At Logitech, I am working within the industrial design team on PWS keyboard layout tool. This tool automates and replaces the previous manual per-key, per-country, and per-size legend and icon placement process in Illustrator by generating layouts directly from commands aligned with established keyboard design rules.
In addition to exporting SVG’s straight into illustrator, the tool serves as a query able knowledge base for keyboard design guidelines.

This project is covered by a non-disclosure agreement, so the details are kept confidential. I'd be happy to talk through my process and role in more depth in a conversation.
